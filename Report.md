# Отчёт по проекту Shop Database MCP

Реализован локальный MCP-сервер на TypeScript/Node.js для безопасного анализа `shop.db` через стандартный ввод/вывод. Сервер открывает базу только для чтения и предоставляет два инструмента: `inspect_database` и `query_database`.

## Результаты запросов

`inspect_database` возвращает JSON со списком таблиц, их назначением, столбцами, первичными и внешними ключами, а также количеством строк. При проверке рабочей базы были получены таблицы: `customers` — 150 строк, `order_items` — 1900, `orders` — 750, `products` — 50.

`query_database` принимает один параметризованный запрос `SELECT` или `WITH ... SELECT` и возвращает `columns`, `rows`, `rowCount`, `limit`, `offset` и `hasMore`. Например, группировка заказов по статусу вернула: `cancelled` — 102, `completed` — 313, `new` — 99, `processing` — 106, `shipped` — 130.

Попытка выполнить `DELETE FROM orders WHERE 1 = 0` была отклонена до выполнения с сообщением: `Query rejected: only one read-only SELECT statement is allowed.`

## Безопасность

Защита от записи реализована несколькими уровнями: SQLite открывается в режиме read-only, включается `query_only`, SQL разбирается с учётом строк, комментариев и идентификаторов в кавычках, запрещаются операции изменения данных и схемы, а размер страницы ограничен 200 строками.

## Расход токенов

По данным журнала текущей сессии Codex на момент создания отчёта использовано **1 508 181 токенов**: 1 488 837 входных, из них 1 414 400 кэшированных; 19 344 выходных; 3 925 токенов рассуждений. Значение отражает счётчик всей сессии задачи.
